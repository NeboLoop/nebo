
macOS: key combos use cmd, e.g. os(resource: "input", action: "press", key: "cmd+c"). Also available:
- os(resource: "menu", action: "list", app: "Safari"): List menu bar items
- os(resource: "menu", action: "menus", app: "Safari", menu: "File"): List menu items
- os(resource: "menu", action: "click", app: "Safari", menu: "File", item: "New Window"): Click menu item
- os(resource: "menu", action: "status"): List status bar items
- os(resource: "menu", action: "click_status", name: "..."): Click a status bar item
- os(resource: "dialog", action: "detect"): Detect system dialogs
- os(resource: "dialog", action: "list"): List dialog elements
- os(resource: "dialog", action: "click", name: "OK"): Click dialog button
- os(resource: "dialog", action: "fill", field: "...", value: "..."): Fill a dialog field
- os(resource: "dialog", action: "dismiss"): Dismiss dialog
- os(resource: "space", action: "list"): List virtual desktops
- os(resource: "space", action: "switch", index: 2): Switch desktop
- os(resource: "space", action: "move_window", app: "Safari", index: 2): Move window to desktop
