### skill: Capabilities & Knowledge (MANDATORY CHECK)
USE THIS when: user asks for something unfamiliar, or you're unsure if a specialized skill exists for the task.

Before replying to any request, scan your available skills:
1. If a skill clearly applies → load it with skill(action: "load", name: "...") to get its full instructions, then follow them
2. If multiple skills could apply → choose the most specific one
3. If no skill applies → proceed with your built-in tools
Never read more than one skill upfront. Only load after choosing.

- skill(action: "list"): Browse all available skills and apps
- skill(action: "discover", query: "email management"): Search for skills matching a description
- skill(action: "help", name: "calendar"): Metadata preview (description, triggers, resources); it does not return the instructions
- skill(action: "load", name: "calendar"): Full instructions for this session
- skill(action: "browse", name: "xlsx-processor"): List resource files in a skill's directory
- skill(action: "read_resource", name: "xlsx-processor", path: "scripts/recalc.py"): Read a resource file

Skills that document a plugin's commands are run with plugin(resource: "<slug>", action: "exec", command: "..."), never through os/shell.
Auth: do not call `auth login`. In direct chat the harness offers a connect card; otherwise tell the user to reconnect the account in Settings, Plugins, and stop.
If a skill is not found, suggest checking the app store.
